صفحه اینستاگرام
فقط آیدی کافیه (بدون @)؛ یا آدرس کامل صفحه رو بچسبون. همین آدرس برای ساختن کیوآر کد بخش «اشتراک‌گذاری» بالای همین تب استفاده می‌شه.
ذخیره‌سازی عکس محصولات (گیت‌هاب)
مخزن گیت‌هاب Public هست، پس هر دستگاهی که این لینک رو باز کنه خودکار و بدون نیاز به توکن، آخرین داده‌ها رو می‌بینه. اما برای ثبت تغییرات (سفارش، محصول، عکس و ...) هر دستگاه باید یک Personal Access Token خودش رو اینجا وارد کنه؛ یک توکن با دسترسی نوشتن روی همین مخزن بساز (ترجیحاً fine-grained و محدود به همین ریپو). این توکن فقط روی همین گوشی/مرورگر ذخیره می‌شه و هیچ‌وقت داخل خود مخزن یا لینک قرار نمی‌گیره؛ فقط به افرادی بده که بهشون اعتماد داری.
از github.com → Settings → Developer settings → Personal access tokens بساز؛ دسترسی نوشتن (Contents: Read and write) روی همین مخزن کافیه.
همگام‌سازی داده‌ها با گیت‌هاب
تنظیمات، محصولات، سفارش‌ها و فروش‌ها توی یک فایل data.json در ریشه همون مخزن ذخیره می‌شن. چون مخزن Public هست، همه‌ی دستگاه‌ها بدون نیاز به توکن این فایل رو می‌خونن و آخرین نسخه رو می‌بینن. برای ذخیره‌ی تغییرات جدید (نوشتن روی همین فایل)، همون دستگاه باید توکن گیت‌هابش رو بالا وارد کرده باشه. توکن گیت‌هاب هیچ‌وقت داخل این فایل ذخیره نمی‌شه.
پشتیبان‌گیری
اطلاعات فقط روی همین گوشی ذخیره می‌شود. برای اینکه در صورت پاک شدن حافظه یا تعویض گوشی چیزی از دست نرود، هر از گاهی یک فایل پشتیبان بگیرید.
